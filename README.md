# 📌 Напоминалка — приложение для Windows 11

Десктопное приложение-напоминалка на Python с графическим интерфейсом (tkinter) и хранением данных в SQLite3. При наступлении времени показывает системные уведомления Windows — даже если окно программы свёрнуто.

## Возможности

- **Добавление напоминаний** — заголовок, описание, дата и время срабатывания
- **Удаление напоминаний**
- **Смена статуса** — «Готово» или «Отменено»
- **Автоматический перевод просроченных** — напоминания с наступившим временем помечаются как «Просрочено»
- **Фильтр по статусу** — Все / Ожидает / Готово / Просрочено / Отменено
- **Уведомления поверх окон** — всплывающие уведомления Windows, работают в фоне
- **Автосоздание БД** — таблица `reminders` создаётся при первом запуске

## Статусы напоминаний

| Статус | Цвет в таблице | Описание |
|---|---|---|
| Ожидает | 🔵 Синий | Создано, время ещё не наступило |
| Готово | 🟢 Зелёный | Пользователь отметил как выполненное |
| Просрочено | 🔴 Красный | Время прошло, не отмечено как «Готово» |
| Отменено | ⚪ Серый | Пользователь отменил напоминание |

## Требования

- **ОС:** Windows 10/11
- **Python:** 3.10+
- **Стандартная библиотека:** `tkinter`, `sqlite3`, `threading`, `datetime` (входят в поставку Python)
- **Дополнительно (одно на выбор):**

  ```bash
  # Рекомендуется — нативные уведомления Windows 10/11
  pip install win10toast

  # Альтернатива — кроссплатформенные уведомления
  pip install plyer
  ```

  Если ни одна библиотека не установлена, уведомления показываются через `messagebox` поверх всех окон — как запасной вариант.

### Назначение файлов

| Файл | Описание |
|---|---|
| `main.py` | Главное окно приложения. Класс `ReminderApp` — кнопки, таблица, диалоги, фильтр. Запускает фоновый поток уведомлений при старте и останавливает при закрытии. |
| `db.py` | Слой базы данных. Набор функций для работы с SQLite3: создание таблиц, CRUD-операции, авто-перевод просроченных. Классов нет — процедурный стиль. |
| `notifications.py` | Фоновый daemon-поток. Каждые 30 секунд проверяет наступившие напоминания и показывает уведомления. Работает независимо от состояния окна tkinter. |

## Схема базы данных

```sql
CREATE TABLE reminders (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    title       TEXT    NOT NULL,
    description TEXT    DEFAULT '',
    due_at      TEXT    NOT NULL,                  -- 'YYYY-MM-DD HH:MM'
    status      TEXT    NOT NULL DEFAULT 'Ожидает',
    created_at  TEXT    NOT NULL DEFAULT (datetime('now','localtime'))
);
```

Формат `due_at` — строка `ГГГГ-ММ-ДД ЧЧ:ММ` (например, `2026-10-07 14:30`).

## Использование

### Добавить напоминание

1. Нажмите **«Добавить»**
2. Введите заголовок (обязательно), описание (необязательно)
3. Укажите дату и время в формате `ГГГГ-ММ-ДД ЧЧ:ММ`
   - Кнопки **+1ч** и **+1д** — быстрое заполнение (через час / через день)
4. Нажмите **«Сохранить»**

### Удалить напоминание

1. Выделите строку в таблице
2. Нажмите **«Удалить»**
3. Подтвердите удаление

### Отметить как «Готово» или «Отменено»

1. Выделите строку
2. Нажмите **«Отметить «Готово»»** или **«Отменить»**

### Фильтр по статусу

Выберите значение в выпадающем списке «Фильтр» — таблица обновится автоматически.

### Обновить список

Нажмите **«Обновить»** — таблица перечитает данные из БД и применит авто-перевод просроченных.

## Как работают уведомления

1. При запуске приложения стартует фоновый daemon-поток (`notifications.start()`)
2. Поток проверяет напоминания каждые **30 секунд** (`CHECK_INTERVAL` в `notifications.py`)
3. Сначала вызывается `db.mark_overdue()` — переводит просроченные из «Ожидает» в «Просрочено»
4. Затем берёт напоминания в статусе «Ожидает» с наступившим временем и показывает уведомление
5. После показа уведомления напоминание переводится в «Просрочено», чтобы не повторяться

Поток работает независимо от окна tkinter — уведомления приходят даже при свёрнутом приложении.

### Изменить интервал проверки

В файле `notifications.py`:

```python
CHECK_INTERVAL = 10  # по умолчанию 30 секунд
```

## Демонстрация работы

Подробный сценарий демонстрации — в каждом шаге проверяется одна функция приложения. См. раздел «Возможности» выше или запустите приложение и добавьте напоминание на ближайшую минуту.

## Технические детали

- **SQLite3** — встроенная библиотека Python, отдельный сервер не нужен
- **WAL-режим** — включён через `PRAGMA journal_mode=WAL` для конкурентного доступа
- **row_factory** — результаты запросов возвращаются как словари (`dict`), удобный доступ по именам колонок
- **daemon-поток** — фоновый поток помечен как daemon, завершается автоматически при закрытии приложения
- **Валидация статусов** — `db.update_status()` проверяет, что передан один из допустимых статусов из `VALID_STATUSES`
